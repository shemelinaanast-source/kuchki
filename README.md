# ☁️ Кучки вдохновения

Личная карта того, что вдохновляло в разные периоды жизни. Каждый период —
**кучка**: мягкая градиентная сфера. Внутри каждой — то, что тогда трогало:
песни, картинки, цитаты, цели.

## Две версии

- **`index.html` — туман (главная).** Никакой линии и интерфейса: сферы-кучки
  бродят во весь экран в светлом тумане. Время — это глубина: свежие ближе и
  чётче, давние дальше и размыты.
  - тяни — бродить, колесо — глубже или дальше, курсор даёт параллакс;
  - клик по сфере — провалиться внутрь: её цвет становится всем миром,
    вещи плавают размытыми и становятся резкими у курсора (линза фокуса);
  - Esc, прокрутка назад или «наружу» — вынырнуть.
- **`classic.html` — классическая версия** из макета: сферы на пунктирной
  линии, пространство кучки с полосой-заголовком. Пока **добавлять вещи можно
  только здесь** (строка ввода, кнопка «файл», перетаскивание, mp3) — туман
  видит всё сразу, данные общие.

### Как откатиться на линейную версию

Линейная версия сохранена меткой `v1-linear`:

```bash
git checkout v1-linear
```

Вернуться к актуальной: `git checkout main`.

## Где хранятся данные

Всё сохраняется **в этом браузере** (IndexedDB) автоматически, на каждое
изменение: кучки, фото, треки. В репозиторий личные данные не попадают.

Важно: данные привязаны к браузеру и адресу (`http://localhost:5510`).
Если открыть другой браузер или очистить данные сайтов — там будет пусто.
Экспорт в файл на компьютере — следующий шаг.

## Структура проекта

```
Большая практика_2/
├── index.html          # главная: кучки в тумане (стили и логика внутри файла)
├── classic.html        # классическая версия: линия, пространство кучки, ввод
├── css/
│   ├── base.css        # механика: позиции, слои, скрытие (лучше не трогать)
│   └── style.css       # дизайн — сейчас пустой, внутри карта всех элементов
├── js/
│   ├── utils.js        # палитры, цвета, даты, хэши, распознавание ссылок
│   ├── sample.js       # примеры кучек для первого запуска
│   ├── state.js        # общее состояние и ссылки на элементы страницы
│   ├── store.js        # сохранение в браузере (IndexedDB)
│   ├── tags.js         # чтение ID3-тегов mp3 (название, исполнитель, обложка)
│   ├── map.js          # карта: ветка, облачка, превью, сетка, камера
│   ├── space.js        # пространство внутри кучки
│   ├── player.js       # проигрывание mp3 на дисках
│   ├── add.js          # строка ввода, файлы, перетаскивание, вставка
│   └── app.js          # новая кучка, горячие клавиши, запуск
├── server.rb           # маленький локальный сервер (UTF-8 safe)
├── build.rb            # сборка в один HTML-файл для Claude Artifact
├── .claude/
│   └── launch.json     # конфиг запуска сервера
└── README.md
```

Скрипты подключаются обычными `<script>` по порядку из `classic.html` и делят
общие переменные, поэтому порядок в `classic.html` важен.

## Как запустить

Нужен только **Ruby** (есть в macOS из коробки). Из папки проекта:

```bash
ruby server.rb 5510
```

Затем открыть в браузере:

```
http://localhost:5510/
```

Классическая версия: `http://localhost:5510/classic.html`

> Свой `server.rb` нужен потому, что встроенный в Ruby WEBrick падает на
> кириллице в имени папки. Открывать `index.html` двойным кликом не стоит:
> у `file://` своё отдельное хранилище, и данные будут жить отдельно.

## Сборка в артефакт

```bash
ruby build.rb
```

Создаёт `dist/kuchki.bundle.html` — один самодостаточный файл со встроенными
стилями и скриптами.

## Технологии

- **HTML / CSS** — без фреймворков; механика в `base.css`, внешний вид в `style.css`.
- **Vanilla JavaScript** — логика, классические `<script>` без сборщика.
- **SVG** — ветка и синапсы.
- **IndexedDB** — сохранение кучек и треков в браузере.
