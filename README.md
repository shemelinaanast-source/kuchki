# ☁️ Кучки вдохновения

Личная карта того, что вдохновляло в разные периоды жизни. Каждый период —
**кучка**: светящийся сгусток энергии на белой бумаге с розовой карандашной
сеткой. Кучки сидят на одной цветной ветке времени, а внутри каждой — своё
пространство, куда можно просто вкидывать песни, картинки, цитаты и цели.

Так видно, что вдохновляло тогда, как менялось, и где были тихие периоды.

## Что умеет

- **Карта жизни** — бесконечный холст, панорама и зум как в Figma
  (колесо — двигать, ⌘/Ctrl + колесо или щипок — зум, Shift+1 — показать всё).
- **Кучки-облачка** — цвет берётся из фона кучки; чем больше вещей, тем гуще
  облачко; у тихих периодов оно бледнеет само.
- **Обложка кучки** — одну вещь внутри можно сделать главной, и она встанет
  в сердце облачка на карте.
- **Превью** — наведи на кучку или приблизь карту, и облачко раскроется
  коллажем того, что внутри.
- **Синапсы** — если одна и та же песня или фраза есть в разных периодах,
  между ними появляется едва заметная нить.
- **Пространство кучки** — свой фон, название, «суть периода», вещи можно
  двигать, менять размер, удалять.
- **Песни — голографические диски.** Ссылки (Spotify, YouTube, Яндекс Музыка…)
  открываются по клику, а свои **mp3** играют прямо на диске: название,
  исполнитель и обложка берутся из тегов файла.
- **Новая кучка** — текущий период закрывается сегодняшним днём, и всё новое
  падает уже в новую.

## Где хранятся данные

Всё сохраняется **в этом браузере** (IndexedDB) автоматически, на каждое
изменение: кучки, фото, треки. В репозиторий личные данные не попадают.

Важно: данные привязаны к браузеру и адресу (`http://localhost:5510`).
Если открыть другой браузер или очистить данные сайтов — там будет пусто.
Экспорт в файл на компьютере — следующий шаг.

## Структура проекта

```
Большая практика_2/
├── index.html          # разметка страницы
├── css/
│   └── style.css       # все стили: бумага, облачка, диски, интерфейс
├── js/
│   ├── utils.js        # палитры, цвета, даты, хэши, распознавание ссылок
│   ├── sample.js       # примеры кучек для первого запуска
│   ├── state.js        # общее состояние и ссылки на элементы страницы
│   ├── store.js        # сохранение в браузере (IndexedDB)
│   ├── tags.js         # чтение ID3-тегов mp3 (название, исполнитель, обложка)
│   ├── map.js          # карта: ветка, облачка, превью, сетка, камера
│   ├── space.js        # пространство внутри кучки
│   ├── player.js       # проигрывание mp3 на дисках
│   ├── add.js          # строка ввода, файлы, перетаскивание, вставка
│   └── app.js          # новая кучка, горячие клавиши, запуск
├── server.rb           # маленький локальный сервер (UTF-8 safe)
├── build.rb            # сборка в один HTML-файл для Claude Artifact
├── .claude/
│   └── launch.json     # конфиг запуска сервера
└── README.md
```

Скрипты подключаются обычными `<script>` по порядку из `index.html` и делят
общие переменные, поэтому порядок в `index.html` важен.

## Как запустить

Нужен только **Ruby** (есть в macOS из коробки). Из папки проекта:

```bash
ruby server.rb 5510
```

Затем открыть в браузере:

```
http://localhost:5510/
```

> Свой `server.rb` нужен потому, что встроенный в Ruby WEBrick падает на
> кириллице в имени папки. Открывать `index.html` двойным кликом не стоит:
> у `file://` своё отдельное хранилище, и данные будут жить отдельно.

## Сборка в артефакт

```bash
ruby build.rb
```

Создаёт `dist/kuchki.bundle.html` — один самодостаточный файл со встроенными
стилями и скриптами.

## Технологии

- **HTML / CSS** — вся визуальная часть, без фреймворков.
- **Vanilla JavaScript** — логика, классические `<script>` без сборщика.
- **Canvas** — карандашная сетка; **SVG** — ветка и синапсы.
- **IndexedDB** — сохранение кучек и треков в браузере.
- **Google Fonts** — JetBrains Mono, Pixelify Sans.
